2 .Modelos Probabilísticos

Los modelos probabilísticos son herramientas matemáticas que se usan para representar situaciones donde hay incertidumbre o azar. En lugar de dar un único resultado fijo, describen qué tan probable es que ocurran distintos resultados.

Como se clasifican los modelos probabilísticos

Los modelos probabilísticos se pueden clasificar de varias formas, dependiendo de qué aspecto se quiera analizar (tipo de variables, estructura, tiempo, etc.).

Según el tipo de variables

1. Modelos Discretos

Las variables toman valores contables (0, 1, 2…). Cómo por ejemplo el número de personas que llegan a una tienda.

Ejemplos:

-Distribución binomial

-Distribución de Poisson

-Distribución hipergeométrica

2. Modelos Continuos

Las variables pueden tomar cualquier valor en un intervalo.Como la altura, peso, temperatura.

Ejemplos:

-Distribución normal

-Distribución exponencial

-Distribución uniforme

4 .Distribución Binomial

La distribución binomial es uno de los modelos probabilísticos más importantes. Se usa cuando analizas experimentos con dos posibles resultados (éxito o fracaso).

Características de la distribución binomial

La distribución binomial describe el número de éxitos en varios intentos repetidos de un experimento.

1. Número fijo de ensayos

Se realizan ( n ) intentos (por ejemplo, lanzar una moneda 10 veces).

2. Solo dos resultados posibles

Cada intento tiene solo:

-Éxito (ej: cara)

-Fracaso (ej: sello)

3. Probabilidad constante

La probabilidad de éxito ( p ) es la misma en todos los ensayos.

4. Ensayos independientes

El resultado de un intento no afecta a los demás.

5. Variable aleatoria discreta

Cuenta cuántos éxitos hay:

X = 0, 1, 2, ..., n Fórmula

La probabilidad de obtener exactamente ( k ) éxitos es:

P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}

Medidas importantes

Media (esperanza):

\mu = n p

Varianza:

\sigma^2 = n p (1 - p)

Desviación estándar:

\sigma = \sqrt{n p (1 - p)}

5 .Ejercicio 1

10 .Distribución Poisson

La distribución de Poisson es una distribución de probabilidad discreta que se usa para modelar la cantidad de veces que ocurre un evento en un intervalo de tiempo, espacio o área, cuando los eventos ocurren de manera independiente.

Por ejemplo:

-Número de llamadas que recibe una empresa en una hora.

-Cantidad de accidentes en una carretera por día.

-Número de clientes que llegan a una tienda.

Su fórmula es:

P(X=x)=\frac{e^{-\lambda}\lambda^x}{x!}

Donde:

X = número de eventos.

x = valor específico que queremos calcular.

\lambda = promedio de ocurrencias.

e ≈ 2.71828.

Características

-La variable toma valores enteros: 0, 1, 2, 3…

-El promedio y la varianza son iguales a \lambda.

-Se usa cuando los eventos son raros o aleatorios.

16 .Distribución Hipergeométrica

La distribución hipergeométrica es una forma de calcular probabilidades cuando estás trabajando con una población finita y haces extracciones sin reemplazo, es decir, cada elemento que sacas ya no vuelve a la población. Esto hace que las probabilidades cambien en cada extracción.

Se utiliza cuando se tiene:

  • Una población total de tamaño ( N )

  • Dentro de esa población hay ( K ) elementos que se consideran “éxitos”

  • Se toma una muestra de tamaño ( n )

  • Se quiere saber la probabilidad de obtener exactamente ( k ) éxitos.

Fórmula

P(X = k) = \frac{\binom{K}{k},\binom{N-K}{n-k}}{\binom{N}{n}}

Características

1.Población finita. Hay un número limitado de elementos.

Ejemplo: 20 estudiantes, 50 piezas, 100 productos.

2. Sin reemplazo. Los elementos NO se devuelven después de ser seleccionados. Esto hace que cada extracción cambie las probabilidades.

3.Solo dos tipos de elementos. La población se divide en dos grupos:

  • Éxitos (K): lo que interesa

  • Fracasos (N − K): el resto

Ejemplos:

  • defectuoso / no defectuoso

  • rojo / azul

  • aprobado / reprobado

4. Muestra fija.Se selecciona un número fijo de elementos ( n ).

5. Dependencia entre eventos. Cada extracción afecta la siguiente. No son independientes como en la binomial.
